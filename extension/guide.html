Manga Reader

Set it up once, then let it read your manga aloud.

What you need

  • A Windows PC with an NVIDIA graphics card: at least 4 GB of graphics memory, 9 GB for the best text model.
  • Any Chromium-based browser, like Chrome or Brave.

1 Install Ollama

Ollama reads the text in the pictures.

  1. Download and install it from ollama.com.
  2. Open PowerShell and run these two commands: 
    ollama pull qwen3-vl:4b-instruct
    [Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', 'chrome-extension://*', 'User')
  3. Restart Ollama: right-click its icon at the bottom right of the taskbar, choose Quit, then open it again.

2 Start the local server

It finds the speech bubbles and gives you the natural voices.

  1. Install Python from python.org. Tick Add python.exe to PATH during setup.
  2. Open PowerShell in the Manga Reader folder and run: 
    pip install torch --index-url https://download.pytorch.org/whl/cu128
    pip install -r tts-server\requirements.txt
  3. Double-click tts-server\start.bat and keep its window open while you read.

After restarting your PC, double-click start.bat again.

3 Add the extension

  1. Open your browser's extensions page and turn on Developer mode.
  2. Click Load unpacked and choose the extension folder.

If you can see this page, this step is done.

Read

Open a chapter, click the extension icon and press Start reading (or Alt+Shift+R). Each bubble is read when it's fully on screen.

Change the text model or voice

Text model: download another one in PowerShell, then pick it in the popup.

ollama pull qwen3-vl:8b-instruct

Voices: add or remove voices in tts-server\settings.json, then restart start.bat.

Something's wrong?

The popup shows three status marks. Hover one to see what's wrong.

Text reader is red
Make sure Ollama is open, and redo step 1.
Bubbles or Voice is amber
The local server isn't running. Double-click tts-server\start.bat.
Reading is slow
Pick a smaller text model in the popup.
